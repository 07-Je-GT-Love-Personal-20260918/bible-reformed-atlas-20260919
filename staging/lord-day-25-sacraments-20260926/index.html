The Big Picture

先跳出“圣礼”这个题目：主日25真正是在回答“软弱的信心怎样被神牧养？”

主日23–24刚刚讲完“唯独因信称义”和“善行不能成为我们的义”。紧接着主日25不是突然换题，而是追问：既然人唯独藉信与基督联合、领受祂一切恩惠，那么这信从哪里来？又怎样在漫长、摇摆、常被控告的人生中被坚固？答案不是“靠自己把信心练大”，而是神主动供应祂所设立的恩典媒介。

圣言告诉你：“基督为罪人舍己。”　圣礼仿佛把神自己的“印章”盖在这应许上，对信徒说：“这福音的应许也真实地临到你。”
圣灵信心的真正作者，不是人的自我说服
福音宣讲藉听道生发信心，内容是基督和祂的工作
真信心抓住基督，而不是抓住自己的感觉
圣礼施行把同一福音以可见标志与印记呈现
信心得坚固不是增加新的救恩，而是加深对同一应许的确信
基督一次献祭所有箭头最后都落在十字架，而不是落在仪式本身

最容易忽略的一句话

Q67把“圣言”和“圣礼”绑在一起：二者都使我们的信心专一地朝向基督一次完成的献祭。改革宗圣礼观的安全栏就在这里——圣礼绝不成为第二个救恩根基。

Historical & Textual Context

真实背景：三个现场叠在一起

① 埃及的夜晚

出埃及记12章发生在十灾的高潮。以色列并不是在安全环境里举行一个纪念礼仪，而是在审判临近、死亡越门而过的夜晚，按神的话预备羊羔、把血涂在门框上、急速吃逾越节筵席。标志本身不是救主；神所应许并指定的血之标志，把百姓的信心引向神的拯救。

② 罗马书的论证

罗马书4章承接3章“因信称义”的论证。保罗以亚伯拉罕为例：他在受割礼以前已因信被算为义；之后才领受割礼作为“标志和印记”。因此，圣礼不是制造称义，而是印证神已经在福音中应许的义。

③ 1563年的海德堡

《海德堡要理问答》在普法尔茨教会改革与教导统一的处境中形成。主日25以极简洁的结构把宗教改革核心说清：信心出于圣灵，圣灵藉福音生发信心，藉圣礼坚固信心；圣礼所印证的中心不是人的功德，而是基督一次完成的献祭。

前后文的关键连接主日23：我怎样在神面前称义？——唯独因真信心接受基督。主日24：善行为什么不能成为义？——因为最好的行为也不完全。主日25：那使我有份于基督的信心从哪里来、怎样坚固？——圣灵藉圣言生发，藉圣礼坚固。于是逻辑不是“信心 → 再加圣礼才得救”，而是“基督 → 福音应许 → 圣灵赐信 → 圣礼坚固这信”。

Q65–68

逐问解读：四问实际上是一条完整的逻辑链

Q65｜信从哪里来？

答案：从圣灵而来；圣灵藉福音的传讲在心里生发信心，并藉圣礼的施行使之坚固。

本质：信心本身也是恩典。人的责任是真实地听、回应、悔改、相信；但使死心苏醒、使人抓住基督的是圣灵。

Q66｜圣礼是什么？

三个词：圣洁的、可见的、标志与印记。

目的：更完整地宣告并印证福音应许——赦罪与永生完全因基督一次献祭而赐下。

Q67｜圣言与圣礼为何并列？

不是两种福音。圣言与圣礼在内容上同指一个基督、同一十字架、同一应许。差别在媒介：圣言主要藉听见教导，圣礼藉可见、可触、可吃喝的记号来确认。

Q68｜为什么只有两个？

改革宗标准：必须是基督在新约中设立、带有可见记号、附有福音应许、赐给全教会使用的圣礼。洗礼与圣餐符合此条件。

Sermon Manuscript

讲章：神赐下圣礼，为要坚固我们软弱的信心

中心命题神并不因我们的信心软弱就降低福音的真实性；相反，祂藉圣灵、圣言与圣礼，把我们的眼睛一次又一次从自己转向基督，使我们在摇摆中仍能凭应许而活。

引言｜我们最大的误区：把“我现在感觉怎样”当作“神的应许是否真实”

信徒常有一种隐秘的逻辑：今天祷告有力量，我便觉得神靠近；今天犯罪、灰心、祷告乏力，我便怀疑神的应许。于是救恩的确据被绑在情绪曲线上。主日25恰恰把我们从这种内向的循环里拉出来：你得救的根基不是你对自己的把握，而是基督已经完成的工作；你信心的作者不是你自己，而是圣灵；你信心软弱时，神没有让你凭空制造更强烈的感觉，而是把你带回福音，又藉祂亲自设立的圣礼确认同一福音。

所以圣礼的牧养价值，正在于它把确据从“我里面现在有什么”转回“神在基督里已经作了什么，并且祂现在向我应许什么”。

1

圣礼是圣洁的：因为它属于神、由神设立、为圣洁的福音目的分别出来

“圣洁”首先不是说水、饼、酒在物质层面变成一种神秘物质；而是说它们被神从日常用途中特别分别出来，服事神所设立的圣约行动。

一、圣洁来自设立者，不来自人的加工

普通的水仍是水，普通的饼和酒仍保有其受造物性质；但当它们按照基督的命令在教会中施行，并与神的话和应许相连时，它们被用于圣洁的用途。圣礼的尊严不来自礼仪华丽程度，不来自主持者个人的属灵强度，而来自基督的设立。

二、因此我们既不可轻看，也不可迷信

轻看圣礼，是把神为软弱信徒预备的恩典媒介当作可有可无；迷信圣礼，则是把记号从基督和福音中分离，仿佛动作本身自动施恩。改革宗拒绝这两个极端：既高举圣礼的客观设立，也坚持圣灵按祂的应许借着信心使圣礼真正成为信徒的益处。

三、出埃及记12章让我们看见“圣洁”的严肃

逾越节的礼仪不是以色列人自己发明的宗教表达。羊羔怎样选、何时宰、血涂在哪里、怎样吃，都由神规定。救赎不由人设计；人只能凭信领受神所指定的拯救方式。新约圣礼同样如此：教会不是圣礼的主人，而是受托的管家。

应用：预备洗礼或领圣餐时，不是问“这个仪式能给我什么感觉”，而是问：“设立这圣礼的主是谁？祂在这里向祂的百姓说了什么？我是否以悔改和信心领受祂的应许？”
2

圣礼是标志：它不让我们停在水、饼、酒上，而把我们的信心指向基督

“标志”的本质，是它指向自身之外的现实。路标若使人只欣赏路标而忘了目的地，就失去功能；圣礼若使人只注意仪式而不仰望基督，同样失去其圣经方向。

一、割礼指向更深的洁净与归属

罗马书4章最重要的次序是：亚伯拉罕先因信被算为义，后领受割礼作为标志。割礼指向立约的归属，也指向更深的“心受割礼”——神必须在人里面作洁净和更新的工作。

二、逾越节指向代替性的拯救

出埃及记12章的血是一个外在标志，但它所指向的是神在审判中借着代替而施行拯救。家庭吃羊羔，不是在“用餐本身”里寻找功德，而是在顺服中承认：我们得存活，是因为神按祂的话预备了代替。

三、洗礼把我们指向基督的洗净与联合

水可见地表现洗净；新约则把信徒的洗礼与基督的死和复活联系起来。水不是基督的血，但水按照基督的命令，指向祂的血真正洁净罪污，以及信徒被带入祂名下、归属于祂。

四、圣餐把我们指向基督舍身流血的救恩

饼被擘开、杯被递出，不是在重复十字架献祭；正相反，圣餐之所以能成为福音的标志，是因为献祭已经一次完成。教会在吃喝中宣告主的死，直到祂来。

应用：每当看见洗礼的水、圣餐的饼与杯，就训练自己的心说：“不要停在记号上。记号正在把我带回那位被钉、复活、赐生命的基督。”
3

圣礼是印记：神把祂福音应许的可靠性再次印在信徒的良心上

“标志”回答“它指向什么？”；“印记”回答“神藉此向我确认什么？”

一、印记不是给神看的，是给软弱的我们看的

神的话本来就完全可靠，祂不需要圣礼来使自己的应许变得更真。需要被坚固的是我们。正因为我们的心迟钝、健忘、受控告、容易把注意力拉回自己，神才以可见、身体性的方式重复同一福音。

二、罗马书4章给“印记”最清楚的圣经语言

割礼作为印记，确认的不是亚伯拉罕肉身行为的价值，而是“他在未受割礼时因信所得的义”。换言之，印记把信徒带回神已经应许的义，而不是制造一种新的义。

三、印记如何帮助软弱的良心？

当你说：“我的信心太小，所以神可能不要我。”福音回答：“你的救恩不建立在信心大小，而建立在基督的完全。”圣礼又以可见方式补上一句：“正是这位基督和祂的恩惠，神在祂的约中向祂百姓应许；不要把确据建筑在情绪上，要建筑在神真实可靠的话上。”

四、真正的坚固不是把人带向自信，而是带向基督信靠

圣礼不是让人说“我受过洗，所以不管怎样都安全”或“我领了圣餐，所以自动得恩典”；而是使人说：“我没有任何可以夸口的义；但基督是完全的救主，神的应许不会说谎。我因此悔改，再次凭信投靠祂。”

应用：当感觉控告你时，不要用感觉反驳感觉。让客观的福音应许审判你的感觉：基督的十字架是否完成？神是否可信？圣灵是否会藉祂所设立的方式牧养教会？圣礼正把答案放到你眼前。

结语｜圣礼的方向永远是“离开自己，归向基督”

我们的罪使我们总想把救恩抓在自己手里；我们的软弱又使我们抓不住。福音说：救恩根本不在你手里，而在基督已经完成的工作里。圣礼则把这福音放进教会的时间、身体和群体生活中，使你不是孤零零地靠内心感觉维持信仰，而是在神所召聚的教会里，一再听见、看见、领受同一个应许。

因此，主日25的终点不是“更重视仪式”，而是“更专一地相信基督”。这正形成海德堡完整的牧养闭环：罪使我们不能靠自己站立；救赎完全在基督一次献祭中成就；感恩则使我们在教会中谦卑领受神的话与圣礼，以信心、敬畏与喜乐回应祂。

Discussion Guide

六道讨论题：详细答案与带领思路

下面不是只给“标准答案”，而是给出可以带领小组逐层追问的逻辑：经文事实 → 神学判断 → 误区辨析 → 个人应用。

1. 根据66问，我们怎样才能有份于基督和祂的一切恩惠？真信心怎么产生的？

第一层：有份于基督的方式

严格从主日25的前后文说，我们唯独藉真信心有份于基督和祂一切恩惠。信心不是另一种功德，而是空手领受基督。称义的义在基督里面，不在信心这个动作本身里面。

第二层：真信心的来源

Q65明确说，真信心从圣灵而来。圣灵通常藉福音的宣讲在人的心里工作，使人认识罪、看见基督的充足、悔改并信靠祂。罗10:17所表达的次序正是“信道从听道而来”。

第三层：圣礼处于什么位置

圣礼不是先制造一个“没有福音内容的信”，而是坚固圣灵藉福音所生发的信。可以记成：圣灵是作者，福音是生发信心的主要外在媒介，圣礼是坚固信心的可见福音。

两个：洗礼与圣餐。

什么时候设立？

圣餐是在耶稣被卖、受难前夕与门徒共进最后晚餐时设立；保罗在林前11章把这一传统追溯到“主耶稣被卖的那一夜”。洗礼作为新约普世教会的使命性圣礼，在复活的主颁布大使命时被清楚命令：使万民作门徒，奉父、子、圣灵的名给他们施洗。

为什么设立？

不是因为福音的话不够真实，而是因为我们的信心软弱。神以圣礼更完整地宣告、并印证福音应许，使我们确信赦罪和永生完全因基督一次献祭而来；同时，圣礼也把信徒公开放在教会的圣约生活中——洗礼标明归属，圣餐不断养育和宣告。

3. “圣礼是圣洁的”是什么意思？这对我们看待洗礼和领受圣餐有什么教导和提醒？

“圣洁”不是魔法化

“圣洁”主要意味着被神分别出来，用于祂所设立的圣约用途。水、饼、酒并不因为仪式而失去其受造物性质；圣礼的圣洁来自基督的设立、神的话和圣灵的工作。

两边都要避免

不可轻慢：把洗礼与圣餐看成教会文化附属品、可有可无。不可迷信：把圣礼看成不需要信心、悔改与福音就自动发生功效的动作。

对实际参与的提醒

领受圣餐需要自省，但自省不是寻找“我已经配得”的证据，而是辨认自己的罪与需要、分辨基督的身体、凭信仰望祂。记念洗礼也不是自我保证，而是被提醒：我属于三一神的名，应当以悔改和信心活在这个身份之下。

4. 割礼和逾越节作为标志分别指向什么？洗礼和圣餐怎样把信心指向十字架救恩？

割礼

指向立约的分别与归属，并且旧约先知进一步把它推向“心的割礼”。罗4强调它是亚伯拉罕因信得义的标志和印记，因此它绝不能被理解为肉身动作本身使人称义。

逾越节

指向神在审判中借代替所施行的拯救：羊羔被杀、血成为记号、百姓在筵席中记念被救出为奴之地。它在新约中集中指向基督这真正的逾越节羔羊。

洗礼

水的可见洗净把信徒指向基督的血洁净罪污，并指向与基督的死与复活联合。信心不应停在“我受过一个仪式”，而要越过水看见基督。

圣餐

擘开的饼和递出的杯，把教会带回基督舍身流血；吃喝则表达祂不是遥远的知识对象，而是信徒真正生命的供应。圣餐并不重复十字架，而是宣告一次献祭已经完成。

5. 圣礼作为“印记”，怎样坚固我们对福音应许的确信？信心软弱或被感觉摇动时怎样帮助我们？

印记的逻辑

印记不会使一份虚假的文件变真；它确认本来真实的权威承诺。类似地，圣礼不是让神的话变可靠，而是神体恤我们的软弱，把祂本已真实的福音应许以可见方式确认给我们。

对抗“感觉神学”

当我的感觉说“神今天可能不爱我”，圣礼不叫我寻找更强烈的感觉，而是把我带到一个更客观的问题：基督是否真的为罪人舍命并复活？神是否真的在福音中应许赦罪与生命？若答案是肯定的，那么信心就有比情绪更稳固的落脚点。

但印记不能与信心分离

圣礼的正确使用不是给不悔改者一张“自动保险单”，而是坚固那抓住基督的信心，呼召软弱者再次投靠基督。

6. 今天上午讲道信息的主线是什么？你最深的感触是什么？

主线可浓缩成一句话

神知道我们的信心软弱，所以圣灵藉圣言生发信心，又藉圣礼用可见的标志和印记坚固我们，使我们的确据不建立在自己，而建立在基督一次完成的献祭上。

若要分成三步

第一，圣礼属于神，所以是圣洁的；第二，圣礼指向基督，所以是标志；第三，圣礼确认应许，所以是印记。

可供个人分享的“最深感触”示例

“我常把信心的真实性等同于当天的感觉强不强，但主日25提醒我，神并没有让我用自己的感觉来给祂的应许盖章；相反，是祂用自己的话和圣礼来给福音应许盖章。我的安慰不是‘我抓得多牢’，而是‘基督已经完成，神的应许可信’。”

Extensions

拓展：几个极关键的改革宗辨析

圣礼不是“第二本福音”

圣言和圣礼内容一致，都指向基督。若一个圣礼解释脱离基督十字架，它就已经偏离Q67的控制性原则。

圣礼也不是“只有象征”

改革宗通常不把圣礼缩减为人的主观纪念动作。它是神设立的恩典媒介与圣约行动；圣灵真实地借此坚固信徒，只是这种益处不能与基督、圣言和信心分离。

“一次献祭”是判断一切圣礼论的试金石

来10所强调的是基督献祭的终局性。圣餐若被解释成再度献上基督，就与Q66–67的中心发生冲突。

软弱的信心与虚假的安全感要区分

要理问答安慰的是抓住基督却软弱的信心，不是给拒绝悔改的人提供宗教性的自我安慰。真正的确据使人更依靠基督，也更愿意离弃罪。

↔
与其他改革宗信条的呼应

《比利时信条》33–35条也把圣礼理解为神因我们的软弱而设立的标志与印记，并分别展开洗礼与圣餐。《多特信经》主要聚焦救恩论，但它同样坚持信心与救恩完全出于神恩典的主动工作。三项联合信条在这里并不是三套神学，而是在不同争议点上共同守护“基督、恩典、圣灵、信心、教会”的同一福音结构。

Closed Loops

最后把所有线索闭环

救赎历史闭环

逾越节与割礼 → 预备并塑造旧约百姓 → 基督成为实体 → 十字架一次成就 → 洗礼与圣餐向后指向已成就救恩、向前指向主再来。

圣约神学闭环

立约之神发出应许 → 设立圣约标志 → 召聚可见群体 → 要求以信心领受 → 在基督里实现一切应许 → 继续以圣礼牧养新约教会。

罪—救赎—感恩闭环

罪：我们既不能自救，信心也软弱。救赎：基督一次献祭完全充足。感恩：教会谦卑领受圣言与圣礼，在悔改、信心、敬拜和圣洁生活中回应。

不要问：“我今天感觉自己配得神的应许吗？”
要问：“基督是否已经完成？神是否可信？”
圣礼正是神为第二个问题给软弱信徒的可见确认。
