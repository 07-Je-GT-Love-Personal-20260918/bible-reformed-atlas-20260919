# 整本圣经 · 救赎历史可视化总览

版本：v2.0 · 2026-10-03。单文件响应式学习网站，沿用欧陆改革宗、救赎历史、圣约神学与圣经神学框架。

## 内容概览

- 66 卷圣经卡片、检索与分类筛选
- 救赎历史故事线、时间线及六个年代记忆锚点
- 北国 19 王、南国 20 位统治者的完整顺序和易混淆姓名辨析
- 亚述、巴比伦、波斯、希腊与罗马的时代背景
- 坐标教学地图、古代近东文化区域、出埃及和被掳归回示意图
- 八个关键段落：历史情境、写作目的、正典关联和应用
- 圣约比较表、基督中心的圣经神学思维导图
- 三大普世信经与三项联合信条的条文定位
- 默认展开的讨论答案、记忆卡、学习路线与小测验
- 可隐藏目录、响应式排版与减少动画偏好支持

古代年代存在历法、共同执政和史学差异；页面已标明约数和有争议的节点。地图为教学示意，不能视为精确古代疆界。
